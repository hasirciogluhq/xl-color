# xl-color

ANSI colors and styles for terminal output, for the xlang programming language.

## Commits

- Never add `Co-Authored-By` trailers or any AI attribution to commits, pull requests, tags or release notes unless explicitly asked.
- Write short, clear commit messages that say what changed.

## Development

```sh
xl test                          # unit tests
xl run examples/demo.xl          # every kind of color once
test/run.sh <xlc> <stdlib dir>   # what CI runs
```
